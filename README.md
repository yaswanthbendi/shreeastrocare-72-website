## Getting Started

### Quick Start
Simply open `index.html` in any modern web browser. No build process or dependencies required!

### Local Development
To run the website locally with a development server:

```bash
# Using Python 3
python3 -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000

# Using Node.js (if you have http-server installed)
npx http-server
```

Then open your browser and navigate to `http://localhost:8000`

## Customization

### Colors
All colors are defined as CSS variables in `styles.css`:
```css
:root {
    --color-white: #FFFFFF;
    --color-cream: #FFF8E1;
    --color-gold: #D4AF37;
    --color-royal-blue: #1E3A8A;
}
```

### Fonts
The website uses Google Fonts:
- **Playfair Display**: Headings and display text
- **Montserrat**: Body text and UI elements

If Google Fonts are blocked, the website falls back to system fonts.

### Content
Edit `index.html` to update:
- Service descriptions
- Testimonials
- Contact information
- Gallery items
