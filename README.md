# Shree Astrocare - Professional Astrology Website

A production-ready, elegant astrology website featuring a premium White, Cream, Gold, and Royal Blue color theme.

## 🎨 Theme

This website implements a carefully crafted color palette:
- **White** (#FFFFFF) - Clean backgrounds and text
- **Cream** (#F5F5DC) - Soft, warm backgrounds  
- **Gold** (#FFD700) - Premium accents and CTAs
- **Royal Blue** (#4169E1) - Professional branding and headings

## ✨ Features

- **Responsive Design** - Fully responsive across all devices
- **Modern UI/UX** - Clean, elegant interface with smooth animations
- **Accessibility** - WCAG 2.1 Level AA compliant
- **No Dependencies** - Pure HTML, CSS, and JavaScript
- **SEO Optimized** - Semantic HTML structure
- **Fast Loading** - Optimized performance

## 📋 Sections

1. **Hero** - Engaging introduction with call-to-action
2. **About** - Company overview with feature highlights
3. **Services** - 6 detailed astrology service offerings
4. **Testimonials** - Client reviews and social proof
5. **Contact** - Contact form with validation and info cards
6. **Footer** - Quick links and social media

## 🚀 Quick Start

Simply open `index.html` in your browser or serve with any web server:

```bash
# Using Python
python -m http.server 8080

# Using Node.js
npx http-server

# Then visit http://localhost:8080
```
