## 🚀 Getting Started

### Prerequisites
- Modern web browser
- Python 3 (for local development server)

### Installation
1. Clone the repository
2. Open terminal in the project directory
3. Run local server:
   ```bash
   python3 -m http.server 8000
   ```
4. Open browser to `http://localhost:8000`
